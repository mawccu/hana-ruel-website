# Hana Ruel Paintings

A one-page online shop for an independent oil painter. It's a single HTML file with inline CSS and vanilla JS, no build step.

- **Run it:** open `index.html` in a browser, or serve the folder with `python -m http.server 8000`.
- **Working on it with Claude Code:** read [`HANDOFF.md`](HANDOFF.md) (the full spec: design system, every section and interaction, code map, products, placeholders) and [`CHAT-LOG.md`](CHAT-LOG.md) (how the design got here) before changing anything.

The artist, copy and prices are placeholders, and so are the product photos (from Unsplash). Checkout and the forms aren't connected yet.
